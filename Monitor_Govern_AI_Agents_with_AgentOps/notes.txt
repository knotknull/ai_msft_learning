From my question: 
How to Post Production Deploy eval gates?

Richard Healy replied:
Marc Pulido hi there , if you mean how to do post-production-deploy eval gates, the evaluators on the Evaluate your AI agents page (Task Adherence, Coherence, safety evaluators, plus the agent-specific set — Intent Resolution, Tool Call Accuracy, Response Completeness) aren't dev-only. The difference is the data source:
In development → you point them at a static test dataset (JSONL).
In production → you point them at live traffic via continuous evaluation, which samples a percentage of real agent runs, scores them with the same built-in evaluators, and surfaces the metrics in Foundry Observability + Azure Monitor / Application Insights — so you can alert on quality or safety drift.
You can also run trace evaluation over interactions that already happened, using traces in Application Insights — great for retrospective/incident analysis.
Two things to keep in mind:
AI-assisted evaluators use a judge model, so they cost tokens per scored run — that's why production samples rather than scoring 100% of traffic.
Reference-based evaluators that need a ground_truth answer don't really apply to live traffic; the query+response quality, safety and agent-behaviour evaluators are the ones you carry into prod.
